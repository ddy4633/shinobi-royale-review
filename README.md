# 雾径试炼 · 忍术生存游戏方案

在逐渐缩小的战区里，查克拉既是进攻资源，也是留给下一次脱身的余地。这个仓库交付完整游戏方案，以及一个能实际操作的本地规则样机。

- [完整游戏方案](DESIGN.zh-CN.md)：核心循环、村落与剧情、自由探索、技能、缩圈、地图、公平性、联网和分阶段验收。
- [试玩页面](https://ddy4633.github.io/shinobi-royale-review/)：桌面用方向键或字母键移动，鼠标瞄准，左键或空格施法。选「末圈演练」可直接检查圈伤。

## 本地运行

不需要安装第三方依赖。在仓库根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`。使用本地网页服务，不直接双击页面文件。

运行规则测试：

```sh
node --test test/rules.test.mjs
```
